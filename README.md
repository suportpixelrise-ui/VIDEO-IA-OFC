# VIDEOS IA — histórias cartoon 2D

Projeto de produção audiovisual de Michael. A história atual é **O Prédio que Voltou**, episódio 1, **A cadeira vazia**.

O projeto editável está em [historias/o-predio-que-voltou/episodio-01](historias/o-predio-que-voltou/episodio-01/README-PRODUCAO.md). As referências aprovadas estão em [referencias](historias/o-predio-que-voltou/referencias/).

Inclui narração em português brasileiro, animação limitada 2D por recortes articulados, montagem vertical em Remotion, trilha e efeitos originais, legendas e memória de continuidade. O primeiro episódio termina com escolha A/B e votação ainda não realizada.

Os MP4s exportados permanecem locais. O Git guarda fontes, imagens, áudio de produção, roteiro, legendas e documentação para reabrir e exportar. Nenhuma conta de publicação foi conectada.

Para configurar as ferramentas no Windows, consulte [CONFIGURACAO-VIDEOS.md](CONFIGURACAO-VIDEOS.md). Para o episódio, siga [README-PRODUCAO.md](historias/o-predio-que-voltou/episodio-01/README-PRODUCAO.md).
