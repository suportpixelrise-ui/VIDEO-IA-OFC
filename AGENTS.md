# Produção de vídeos neste workspace (Windows)

- Antes de executar comandos de vídeo em PowerShell, carregue `. .\video-env.ps1` a partir da raiz deste workspace. Esse script coloca Node/npm/npx, FFmpeg/ffprobe e o Python/uv de vídeo no PATH da sessão.
- Use `npm.cmd` e `npx.cmd` no Windows. As ferramentas ficam em `C:\Users\Michael\.codex-video-tools`; as skills pessoais ficam em `C:\Users\Michael\.codex\skills`.
- Remotion oficial já está habilitado pelo plugin. Não instale outra cópia das mesmas skills neste projeto.
- Instagram Skills está configurado em modo manual/rascunho. Esta instalação não autoriza conectar contas, publicar conteúdo ou contratar serviços. Use dados fornecidos pelo usuário para pesquisas sem API.
- Video Shotcraft: consulte a skill instalada e seu `WINDOWS-SETUP.md`. As adaptações do Workbench são locais; uma reinstalação pode substituí-las. Galeria online: https://vincentwei1021.github.io/video-shotcraft/.
- `shotcraft-demo` é a cópia editável do template Ink Press usada para verificar a instalação. Novos trabalhos devem ficar em pastas próprias, preservando esse exemplo e os resultados de verificação.
- Instruções, versões e limitações estão em `CONFIGURACAO-VIDEOS.md`. Não armazene credenciais no repositório.
